# My AI Course - Full Stack AI Bootcamp

A complete collection of coursework, assignments, and hands-on practice from the 6-Month Full Stack AI Bootcamp at Nexskill. This repository covers Python, Data Science, Machine Learning, Deep Learning, Generative AI, and AI Deployment.

---

## Course Duration

6 Months - Full Stack AI Bootcamp (Nexskill)

---

## Topics Covered

### Month 1 - Python and Data Science
- Python Basics and Data Structures
- NumPy for Numerical Computing
- Pandas for Data Manipulation
- Web Scraping with BeautifulSoup and Selenium

### Month 2 - Data Analysis and Statistics
- Exploratory Data Analysis (EDA)
- Data Visualization with Seaborn and Matplotlib
- Statistical Analysis

### Month 3 - Machine Learning
- Logistic Regression
- Decision Trees and Random Forest
- Model Evaluation and Confusion Matrix
- Feature Importance

### Month 4 - Deep Learning
- Neural Networks
- CNN (Convolutional Neural Networks)
- RNN (Recurrent Neural Networks)
- TensorFlow and Keras

### Month 5 - Generative AI and LLMs
- Large Language Models (LLMs)
- ChatGPT and Prompt Engineering
- Hugging Face Transformers
- Fine-Tuning LLMs

### Month 6 - AI Deployment
- LangChain
- RAG (Retrieval Augmented Generation)
- Flask and FastAPI
- Cloud Deployment
