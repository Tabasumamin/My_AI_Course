# California Housing Regression

## About This Project

This project uses housing market data to predict median house value in California districts using housing and demographic features.

## Files Included

- `housing.csv` — dataset containing housing and population features
- `california_housing_regression.ipynb` — notebook with full modeling workflow
- `README.md` — this file

## Dataset Notes

- The dataset typically includes features such as:
  - housing median age
  - total rooms
  - total bedrooms
  - population
  - households
  - median income
  - median house value
- The target variable is `median_house_value`.

## How to Run

1. Open `california_housing_regression.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
2. Ensure `housing.csv` is in the same folder.
3. Run all cells from top to bottom.

## Required Libraries

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## What this Notebook Covers

- Exploratory data analysis
- Handling missing values and outliers
- Feature scaling and transformation
- Training a linear regression model
- Evaluating model performance
- Visualizing predictions and residuals
