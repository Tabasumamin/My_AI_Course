# Salary Regression

## About This Project

This project uses the `Salary_dataset.csv` file to build a regression model that predicts salary based on years of experience and other career factors.

## Files Included

- `Salary_dataset.csv` — dataset with experience and salary values
- `salary_regression.ipynb` — notebook with data exploration, model training, and evaluation
- `README.md` — this file

## Dataset Notes

- The CSV file contains two columns:
  - `YearsExperience`
  - `Salary`
- Data is ready to load from the same folder as the notebook.

## How to Run

1. Open `salary_regression.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
2. Ensure `Salary_dataset.csv` is in the same folder.
3. Run the notebook cells from top to bottom.

## Troubleshooting

- If the notebook cannot find the data, check that `Salary_dataset.csv` is located in `Machine_Learning/Linear_Regression/Salary_Regression/`.
- If data still does not show, restart the notebook kernel and rerun the first cell that loads the CSV.
