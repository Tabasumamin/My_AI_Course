# Linear Regression Module

## About This Module

This folder contains five student-friendly linear regression projects. Each project uses a real dataset to teach regression fundamentals, model building, evaluation, and prediction for continuous target values.

## Included Datasets and Projects

| Dataset | Folder | Notebook | Description |
|---|---|---|---|
| Advertising Regression | `Advertising_Regression` | `advertising_regression.ipynb` | Predict advertising sales from TV, radio, and newspaper budgets. |
| California Housing | `California_Housing` | `california_housing_regression.ipynb` | Predict median house value for California districts using housing and demographic features. |
| Diabetes Regression | `Diabetes Dataset` | `Diabetes_regression.ipynb` | Predict disease progression using medical and lifestyle features. |
| Salary Regression | `Salary_Regression` | `salary_regression.ipynb` | Predict salary from experience, education, and other professional factors. |
| Stock Market Analysis | `Stock_Market_Analysis` | `Stock_Market_regression.ipynb` | Predict stock price trends and values using historical market data. |

## Task

Regression analysis — build and evaluate models that predict a continuous numerical target value.

## How to Use

1. Open the folder for the dataset you want to explore.
2. Place the CSV dataset file in the same directory as the notebook if it is not already present.
3. Open the notebook in Jupyter Notebook, JupyterLab, or Google Colab.
4. Run the notebook cells sequentially from top to bottom.

## Required Libraries

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## What the Notebooks Cover

- Data loading and cleaning
- Exploratory data analysis (EDA) with visualizations
- Feature engineering and selection
- Train/test splitting
- Building linear regression models
- Evaluating models with RMSE, MAE, and R²
- Comparing simple and multiple regression approaches
- Interpretation of coefficients and model results

## Key Learning Outcomes

- Understand the difference between classification and regression
- Prepare tabular data for regression modeling
- Build and evaluate linear regression models using scikit-learn
- Interpret model coefficients and performance metrics
- Compare multiple datasets and regression scenarios

## Notes

- Keep the dataset CSV files together with their corresponding notebook.
- If a notebook includes optional sections, read the comments and try the exercises.
- Use this module to practice regression concepts before moving to more advanced machine learning topics.
