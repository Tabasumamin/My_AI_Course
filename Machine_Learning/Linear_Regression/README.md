# Machine Learning - Linear Regression Practice

## About
This folder contains Linear Regression practice
assignments from the Full Stack AI Course at Nexskill.

## Datasets Practiced

### 1. Advertising Dataset
- Source: Kaggle
- Size: 200 samples, 4 columns
- Target: Sales prediction based on TV, Radio, Newspaper budgets
- Model: Linear Regression
- Tools: Python, Pandas, Seaborn, Scikit-learn

### 2. Salary Dataset
- Source: Kaggle
- Size: 30 samples, 2 columns
- Target: Salary prediction based on experience
- Model: Linear Regression
- Tools: Python, Pandas, Seaborn, Scikit-learn

### 3. California Housing Dataset
- Source: Kaggle
- Size: 20,640 samples, 9 columns
- Target: Median house value prediction
- Model: Linear Regression
- Tools: Python, Pandas, Seaborn, Scikit-learn

### 4. Diabetes Dataset
- Source: Kaggle
- Size: 442 samples, 10 columns
- Target: Disease progression prediction
- Model: Linear Regression
- Tools: Python, Pandas, Seaborn, Scikit-learn

- Train/Test split
