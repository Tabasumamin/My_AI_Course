# Final Assessment Projects

## Overview

This folder contains my final assessment work. I completed four small projects using machine learning and deep learning methods on SpaceX and NASA datasets.

The main purpose of these projects was to practice data loading, data checking, visualizations, feature preparation, model training, model comparison, and saving trained models.

## Projects Included

| No. | Project | Type | Main Work |
| --- | --- | --- | --- |
| 1 | Dataset 1 - SpaceX Stock | Machine Learning | Stock price analysis, regression, classification, clustering, and ensemble models |
| 2 | Dataset 2 - NASA Analytics | Machine Learning | NASA yearly data analysis, budget prediction, activity classification, clustering, and ensemble models |
| 3 | Dataset 3 - SpaceX Missions | Deep Learning | Mission data analysis using RNN, LSTM, and GRU models |
| 4 | Dataset 4 - NASA Analytics | Deep Learning | NASA time series style analysis using RNN, LSTM, and GRU models |

## Folder Structure

|-- Dataset_2_ML NASA Analytics/

Each project folder contains its own notebook, dataset, saved models, and README file.

## Tools Used

- Python
- NumPy

- Seaborn

## How to Run

Open any project folder and run the notebook from top to bottom. The dataset files are stored inside each project's `data/raw` folder.

## What I Learned

Through these projects, I practiced the full workflow of a data science project. I learned how to explore datasets, create useful features, train different models, compare results, and save models for later use.
